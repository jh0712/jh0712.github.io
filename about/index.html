About Me

Senior Full Stack Engineer with 7 years of experience building reliable systems across e-commerce, fintech, and SaaS products.

My journey started in high school, where I had the privilege of representing my school in national programming competitions — an experience that shaped my instinct to focus on the essence of problems, not just making things work.

Each role since has sharpened me in a different dimension:

  • E-commerce — learned to see the full picture: business flows, server operations, and high-traffic architecture
  • Fintech — deepened my engineering craft: system refactoring, independent DB design, advanced Laravel patterns
  • SaaS / AI products — started owning larger responsibilities: stepping up during understaffing, driving requirement planning, cross-functional communication, and consistently delivering measurable results

Selected Achievements

  • Rebuilt Meilisearch batch indexing — cut indexing time for 31,154 job posts from 108+ hours to 5m 18s (~1,200x), turning new-job exposure from 10+ days delayed into real-time
  • Led migration to AWS ECS with auto scaling and scheduled scaling — sustaining 6,000+ peak requests/min with 8–20 dynamically scheduled tasks
  • Fixed 142 frontend dependency vulnerabilities (87 High) down to 1 Low in a single pass, including a Next.js major version upgrade with breaking-change verification on auth/payment flows
  • Built an AI-agent-driven engineering automation system: weekly auto-synced API doc PRs (merged into production), scheduled repo cleanup (-14,100 lines in one run, ESLint warnings -22%), and Trello-triggered AI development flows with guardrails for core features
  • Refactored CI/CD pipeline: deploy time -60%, test execution -51%; replaced Xdebug with pcov to resolve coverage OOM (memory -50%)
  • Tuned OpenSearch resources, cutting monthly cost by 26%
  • Convened cross-functional meetings (including C-level) to resolve a data-loss bug, averting TCPA compliance violations

Tech Stack: PHP · Laravel · Node.js · React · Next.js · MySQL · PostgreSQL · Redis · Docker · AWS (ECS / ECR / S3 / RDS) · OpenSearch · CircleCI · OpenAI API · RAG

To me, good engineering isn’t just about writing code that works — it’s about helping the team move faster, keeping systems maintainable, and spotting risks before they become problems.

資深全端工程師，7 年經驗，橫跨電商、金融科技與 SaaS 產品，專注於打造可靠的系統。

我的旅程始於高中——當時有幸代表學校參加全國程式設計競賽，這段經歷塑造了我的直覺：專注於問題的本質，而不只是讓東西能動。

之後的每一份工作，都在不同的面向磨練了我：

  • 電商 — 學會看見全局：商業流程、伺服器維運、高流量架構
  • 金融科技 — 深化工程功力：系統重構、獨立資料庫設計、進階 Laravel 模式
  • SaaS / AI 產品 — 開始承擔更大的責任：在人力不足時挺身而出、主導需求規劃、跨部門溝通，並持續交出可量化的成果
