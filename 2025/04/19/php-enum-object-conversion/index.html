PHP 枚舉（Enum）在物件轉換中的行為

基本概念

PHP 8.1 引入的枚舉（Enum）提供了定義一組命名常數的方式。PHP 支援兩種類型的枚舉：

  1. 純枚舉（Pure Enums）：僅包含名稱
  2. 備份枚舉（Backed Enums）：包含名稱和對應的值（字串或整數）

備份枚舉的自動轉換行為

備份枚舉在以下情境中會自動轉換為其備份值：

  • 轉換為 JSON
  • 轉換為陣列
  • 序列化
  • 資料庫儲存
  • 作為陣列元素

關鍵特性

  • 當備份枚舉被放入陣列並轉換為 JSON 時，會顯示為其備份值而非枚舉名稱
  • 這種行為是 PHP 的內建特性，不需要額外程式碼
  • 對於字串備份枚舉，會轉換為字串值；對於整數備份枚舉，會轉換為整數值

純枚舉的轉換行為

與備份枚舉不同，純枚舉在轉換時：

  • 不會自動轉換為簡單值
  • 當嘗試 JSON 編碼時會產生錯誤（除非實現 JsonSerializable 接口）
  • 需要手動處理其轉換邏輯

實用技巧

  1. 自訂序列化行為：實現 JsonSerializable 接口可自訂序列化行為
  2. 枚舉方法：可在枚舉中添加方法以提供更多功能
  3. 轉換輔助函數：建立專用函數處理枚舉的特殊轉換需求

效能考量

  • 備份枚舉的自動轉換無需額外處理，效能開銷極小
  • 轉換大量包含枚舉的物件時，效能表現良好

這種自動轉換機制使得 PHP 枚舉非常適合用於 API 回應和資料序列化的情境，無需額外的轉換邏輯即可獲得適合的資料表示形式。
